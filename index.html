» バイブコーディングとは？ «

「コードを書くのではなく、"雰囲気(vibe)" で伝えてAIに作ってもらう。」
— Andrej Karpathy（元Tesla AI責任者）が2025年に提唱

バイブコーディング（Vibe Coding）とは、自然言語（日本語でOK）でAIに指示を出し、プログラムを自動生成してもらう開発スタイルです。 従来のプログラミングのように文法やアルゴリズムを覚える必要はなく、「何を作りたいか」を言葉で伝えることが最も重要なスキルになります。

» 従来のプログラミングとの違い «
従来のプログラミング バイブコーディング
必要な知識 プログラミング言語の文法・アルゴリズム 作りたいものを言語化する力
作業内容 コードを一行ずつ書く AIに指示を出し、結果を確認する
デバッグ エラーを読んで自分で修正 エラーをAIに貼り付けて修正してもらう
学習コスト 高い（数ヶ月〜数年） 低い（今日から始められる）
» 使えるツール紹介 «

バイブコーディングに対応した主要ツールを紹介します。まずは1つ選んで試してみましょう！

Claude Code

CLI / ターミナル

Anthropic製。ターミナル上でプロジェクト全体をAIが把握し、ファイル作成・編集・実行まで自律的に行う。

Cursor

エディタ / IDE

AI搭載コードエディタ。VS Codeベースで、チャットしながらコードを書ける。初心者に人気。

GitHub Copilot

エディタ拡張

VS Code等で使えるAI補完。エージェントモードで指示ベースの開発も可能に。

Bolt / Lovable

ブラウザ完結

ブラウザ上で指示するだけでWebアプリが生成される。環境構築不要で最も手軽。

Replit Agent

ブラウザ完結

オンライン開発環境。自然言語で指示するとアプリを自動構築し、そのままデプロイできる。

v0 by Vercel

UI生成特化

UIデザインを言葉で伝えると、React/Tailwindのコンポーネントを生成。フロントエンド特化。

★ 初心者におすすめ！

環境構築なしで始められる Bolt や Replit Agent がおすすめです。慣れてきたら Cursor や Claude Code にステップアップしましょう。

» はじめ方 — 5つのステップ «

実際にバイブコーディングで何かを作る流れを、順を追って解説します。

1作りたいものを決める

最初は小さなものでOKです。例：

  • じゃんけんゲーム
  • ToDoリストアプリ
  • 自己紹介ページ
  • カウントダウンタイマー

完成形を頭の中でイメージできていると、AIへの指示がブレにくくなります。

2ツールを準備する

一番手軽な方法として、ブラウザで Bolt.new を開くだけでOKです。アカウント登録すればすぐ使えます。

ローカル環境を使いたい場合は、Cursorをダウンロードしてインストールしましょう。

3AIに最初の指示を出す

「プロンプト」と呼ばれる指示文をAIに送ります。日本語で具体的に書くのがコツです。

> あなたの指示:

じゃんけんゲームをHTMLとJavaScriptで作ってください。
- グー・チョキ・パーのボタンが3つある
- ボタンを押すとコンピュータの手がランダムで決まる
- 勝ち・負け・あいこの結果が画面に表示される
- 勝敗の回数をカウントして表示する
- デザインはシンプルでかわいい感じにする
★ 良い指示のコツ

「何が」「どう動いて」「どう見えるか」を箇条書きで伝えると、AIが正確に理解してくれます。曖昧な指示は曖昧な結果を生みます。

4生成結果を確認し、修正を依頼する

AIが生成したコードを動かしてみましょう。思った通りでなければ、追加の指示を出して修正してもらいます。

> 修正の指示（例）:

いい感じです！以下を修正してください：
- ボタンをもう少し大きくして、間隔を空ける
- 結果表示にアニメーションをつける
- リセットボタンを追加する

この「指示 → 確認 → 修正」のサイクルを繰り返して完成度を上げていきます。これがバイブコーディングの基本ループです。

5完成・公開する

満足できる形になったら公開しましょう。BoltやReplitならワンクリックでデプロイ可能です。Vercel や Netlify を使えば無料でWebサイトとして公開できます。

⚠ 注意

AIが生成したコードは必ずしも完璧ではありません。公開前にセキュリティ面（個人情報の取り扱いなど）を確認しましょう。本番サービスとして運用する場合は、コードレビューを受けることをおすすめします。

» プロンプトの実践テクニック «
❶ 役割を与える
あなたは経験豊富なフロントエンドエンジニアです。
以下の要件でReactアプリを作ってください。
❷ 段階的に指示する

一度に全部を頼むのではなく、機能ごとに分けて依頼すると精度が上がります。

// まず土台を作ってもらう
「まずシンプルなToDoリストの基本機能だけ作って」

// 次に機能を追加
「完了したタスクを取り消し線で表示する機能を追加して」

// さらにデザインを調整
「全体をダークモードのデザインに変更して」
❸ エラーはそのまま貼る

エラーが出たら、エラーメッセージをそのままAIに貼り付けましょう。自分で解読する必要はありません。

> あなた:
以下のエラーが出ました。修正してください。

TypeError: Cannot read properties of undefined (reading 'map')
  at App.jsx:15:22
❹ 参考イメージを伝える

「〇〇みたいなデザイン」「△△のような動き」と既存サービスを参考に伝えると、AIが意図を汲み取りやすくなります。

Notionのようなシンプルでクリーンなデザインで、
左側にサイドバー、右側にメインコンテンツという
レイアウトにしてください。
❺ コンテキストを維持する

長い会話では、AIが以前の文脈を忘れることがあります。重要な前提は適宜繰り返しましょう。

★ 上級テクニック

プロジェクトのルールや設計方針をまとめたファイル（例：CONVENTIONS.md）を用意し、AIに毎回読み込ませると一貫性のある出力が得られます。Claude CodeではCLAUDE.mdファイルがこの役割を果たします。

» よくある質問 «
プログラミングの知識がゼロでも大丈夫？

はい、大丈夫です。バイブコーディングの本質は「AIに伝える力」なので、コードが読めなくても始められます。ただし、続けていくうちに基礎知識があると修正指示の精度が上がるため、少しずつ学んでいくとより効果的です。

無料で使えるツールはある？

あります。Bolt.newは無料枠があり、Replit Agentも無料プランがあります。Cursorも無料で始められます。本格的に使い込む場合は有料プラン（月$20前後）が必要になることが多いです。

バイブコーディングで作れないものは？

現状では、大規模で複雑なシステム（銀行の基幹システム等）や、高いパフォーマンスが必要なもの（ゲームエンジン等）は難しいです。一方で、Webアプリ、モバイルアプリ、自動化スクリプト、データ分析ツールなどは十分作れます。

AIが間違ったコードを書いたらどうする？

エラーメッセージをそのままAIに貼り付けて修正を依頼してください。それでも直らない場合は、別のアプローチを提案してもらうか、会話をリセットして最初からやり直すと解決することが多いです。

バイブコーディングを学ぶとプログラマーになれる？

バイブコーディングは「ものを作る力」を身につける入口として最適です。そこからプログラミングの基礎を学んでいけば、プロの開発者を目指すことも十分可能です。まずは作る楽しさを体験し、必要に応じて知識を深めていくのがおすすめです。

作ったものを商用利用していい？

基本的にはAIが生成したコードの商用利用は可能ですが、利用するAIツールの利用規約を必ず確認してください。また、生成されたコードが既存のオープンソースライセンスに抵触しないかも注意が必要です。
